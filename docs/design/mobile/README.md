# Mockup Mobile (Stitch)

20 layar referensi desain untuk aplikasi Face Absen Mobile, diekspor dari
Google Stitch. Setiap folder berisi `code.html` dan `screen.png`.

> **Catatan historis:** sebagian mockup masih memuat copy GPS/geofence dari
> PRD v1.0. Fitur lokasi sudah dihapus dari produk dan kode. Untuk perilaku
> yang berlaku, gunakan [`../../PRD.md`](../../PRD.md) dan kode di
> `mobile/lib/` sebagai sumber kebenaran.
